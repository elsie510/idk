# 🚀 Rocket Countdown Script

A simple Python automation script written by **Elsie He** that executes a timed countdown in the terminal.

## 🛠️ Code

```python
import time

print("Written by Elsie He")
print(10)
time.sleep(1)
print(9)
time.sleep(1)
print(8)
time.sleep(1)
print(7)
time.sleep(1)
print(6)
time.sleep(1)
print(5)
time.sleep(1)
print(4)
time.sleep(1)
print(3)
time.sleep(1)
print(2)
time.sleep(1)
print(1)
time.sleep(1)
print('Take offf!')
```

## 📦 How to Run

1. Make sure you have [Python](https://python.org) installed.
2. Save the code above into a file named `countdown.py`.
3. Open your terminal and run:
   ```bash
   python countdown.py
   ```
